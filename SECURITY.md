# Security scope

This is a fictional-data demo with isolated browser workspaces. It has no verified identities, role-based authorization, session cleanup job, or production rate limiter. Do not use it for real customer records or expose it as an unrestricted production fulfillment service.

Do not include secrets or customer data in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting if enabled; otherwise describe the issue to the maintainer without exploit secrets or personal data.
